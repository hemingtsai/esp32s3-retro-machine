# Retro C 语言规范

Retro C 是本项目 16-bit Retro CPU 使用的一门小型 C 方言。它保留 C 的表达式、函数和控制流结构，但只提供能够由当前指令集直接、可靠实现的类型与操作。

本文定义语言本身。构建和命令行说明见 [`docs/compiler.md`](compiler.md)，指令编码见 [`docs/bytecodes.md`](bytecodes.md)。

## 1. 设计目标

Retro C 面向以下场景：

- 为 Retro Machine 生成可执行的 16-bit word 程序；
- 使用函数、递归和结构化控制流组织逻辑；
- 保持与 C 类似的表达式语法和诊断体验；
- 不依赖 ESP32 原生指针宽度、宿主 ABI 或完整 C 运行时；
- 所有值都可以直接表示为 `u16`。

它不是完整 C，也不尝试兼容某个版本的 ISO C。

## 2. 编译模型

一个 Retro C 翻译单元必须：

- 包含且只包含一个 `u16 main(void)`；
- 可以包含任意数量的 `u16` 或 `void` 函数；
- 可以包含任意数量的 `u16` 全局变量；
- 不需要单独的头文件、链接器或目标文件格式。

函数定义可以按任意顺序出现。编译器先收集全部顶层实体，再生成函数，因此函数可以调用源文件中位于其后的函数。

## 3. 词法

### 3.1 标识符

标识符形式为：

```text
name ::= [A-Za-z_][A-Za-z0-9_]*
```

标识符区分大小写。以下名称不同：

```c
u16 value;
u16 Value;
```

不过 Retro C 生成的符号会交给大小写不敏感的汇编器，因此两个顶层名称不能只相差大小写。下面是错误：

```c
u16 value;
u16 VALUE;
```

以 `__` 开头的名称由编译器保留，用户不能使用。

### 3.2 关键字

关键字区分大小写：

```text
u16 void if else while for break continue return
```

### 3.3 整数常量

支持十进制和显式基数：

```c
0
42
0xff
0b1010
0o17
0xFFFF
```

数字可以使用彼此分隔的下划线提高可读性，但不能以下划线开头、结尾或连续出现：

```c
1_000
0xFF_FF
```

规则如下：

- 常量最终值必须在 `0..65535`；
- 负数不是字面量；
- 一元 `-` 可以在常量前使用，并按 16-bit 无符号模运算生成 `0 - value`；
- 不支持字符常量和字符串；
- 不支持类型后缀，例如 `42U`。

### 3.4 注释

支持行注释和块注释：

```c
// 行注释
/* 块注释 */
```

块注释不能嵌套。

### 3.5 空白和换行

空格、制表符、LF 和 CRLF 均为空白。关键字、标识符、常量和运算符之间按 token 边界解析。

## 4. 类型

Retro C 只有两个基础类型和一个派生形式：

| 类型 | 含义 |
| --- | --- |
| `u16` | 16-bit 无符号整数 |
| `void` | 只能作为函数返回类型 |
| `u16[N]` | 包含 `N` 个 `u16` word 的一维数组 |

数组长度 `N` 必须能表示为 `1..65535` 的整型常量；实际还受局部帧最多 8192 words 和程序数据区布局限制。数组元素大小为一个 16-bit word。

不存在指针、结构体、联合体、枚举、浮点、字符串或有符号整数类型。数组不会退化为指针，不能作为函数参数或整体赋值。

`void` 不能用于变量、参数或表达式值。

## 5. 声明

### 5.1 全局变量

标量语法：

```text
u16 name initializer?
```

一维数组语法：

```text
u16 name[length] initializer?
```

例如：

```c
u16 counter;
u16 mask = 0x8000;
u16 samples[4];
u16 table[5] = {1, 2, 3};
```

全局标量初始化必须是单个整型常量。全局数组初始化使用花括号和整型常量列表：

- 未提供的末尾元素初始化为 0；
- initializer 数量可以少于数组长度；
- initializer 数量超过长度会报错；
- 允许尾逗号；
- 不允许表达式 initializer、指定 initializer 或长度推导。

未初始化的全局标量和数组元素都生成 `.word 0000h`。所有全局数据位于程序代码和内部停机标签之后，运行时不会执行这些数据 word。

### 5.2 函数

语法：

```text
u16 name(parameters) block
void name(parameters) block
```

参数语法：

```text
parameters ::= empty
              | void
              | u16 name { "," u16 name }
```

空参数列表和单独的 `void` 等价。函数最多有 6 个参数。

合法示例：

```c
u16 add(u16 left, u16 right)
{
    return left + right;
}

void reset_counter(void)
{
    counter = 0;
}
```

Retro C 第一版没有独立函数声明。函数必须在同一翻译单元中提供定义。

### 5.3 `main`

每个程序必须定义：

```c
u16 main(void)
```

`main` 的返回值位于 `RS`。程序启动代码调用 `main`，随后执行 `HLT`。

## 6. 表达式

### 6.1 基本表达式

支持：

- 整型常量；
- `u16` 局部变量；
- `u16` 全局变量；
- 一维数组元素 `array[index]`；
- 函数调用；
- 一元表达式；
- 二元表达式；
- 赋值表达式。

函数调用返回 `void` 时，只能作为表达式语句使用。

### 6.2 数组元素

`array[index]` 读取一个 `u16` 元素。`index` 可以是任意非 `void` 的 `u16` 表达式，并且只求值一次。

```c
values[0] = 10;
values[index] += 2;
return values[pick(1)];
```

数组名本身不是 `u16` 值，不能读取、返回、传参或整体赋值。括号可以改变表达式结构：

```c
(values)[index]
```

直接写成整型常量字面量的下标在编译期检查边界；包含算术或函数调用的常量式表达式由运行时检查。动态下标在运行时检查 `index < length`；越界时程序令 `RS = 0xffff` 并执行 `HLT`，不会访问数组范围之外的 word。

### 6.3 运算符优先级

从高到低：

| 优先级 | 运算符 | 结合性 |
| ---: | --- | --- |
| 1 | `array[index]` | 左结合 |
| 2 | `! ~ -` | 右结合 |
| 3 | `* /` | 左结合；只支持 `/` |
| 4 | `+ -` | 左结合 |
| 5 | `<< >>` | 左结合 |
| 6 | `< <= > >=` | 左结合 |
| 7 | `== !=` | 左结合 |
| 8 | `&` | 左结合 |
| 9 | `^` | 左结合 |
| 10 | `|` | 左结合 |
| 11 | `&&` | 左结合 |
| 12 | `||` | 左结合 |
| 13 | 赋值 | 右结合 |

`*` 和 `%` 会被明确拒绝，防止使用者误以为它们可用。

### 6.4 算术和位运算

支持：

```text
+  -  /  &  |  ^  <<  >>
```

所有运算按 16-bit 无符号模 `65536` 运算。

- `ADD`、`SUB` 和逻辑运算自然回绕；
- `/ 0` 触发机器的 `FAULT_DIV_ZERO`；
- 移位量小于 16 时执行目标移位；
- 移位量大于等于 16 时结果为 0，与当前 Retro CPU 一致。

Retro C 不提供乘法、取模、饱和算术或有符号运算。

### 6.5 比较

支持：

```text
<  <=  >  >=  ==  !=
```

比较是无符号 16-bit 比较，结果规范化为 `0` 或 `1`。

### 6.6 逻辑运算和短路

支持：

```text
!  &&  ||
```

语义与 C 一致：

- `!value` 在 `value == 0` 时返回 1；
- `left && right` 在 `left == 0` 时不计算 `right`；
- `left || right` 在 `left != 0` 时不计算 `right`；
- 结果只能是 0 或 1。

短路通过 Retro Machine 的条件跳转实现，不使用运行时 trap。

### 6.7 一元运算

```text
!expression
~expression
-expression
```

示例：

```c
u16 invert(u16 value)
{
    return ~value;
}
```

`-0` 为 0，`-1` 为 `0xffff`。

### 6.8 赋值

支持：

```text
=
+=
-=
/=
&=
|=
^=
<<=
>>=
```

赋值左侧必须是非 `void` 标量局部变量、全局变量或数组元素。数组本身不能整体赋值。赋值结果也是赋入的 `u16` 值，因此可以右结合：

```c
first = second = 3;
```

局部变量地址在右值之前求值。函数实参按从左到右的顺序求值。

## 7. 语句

### 7.1 表达式语句

```c
sum += value;
touch();
```

丢弃表达式结果。

### 7.2 声明语句

局部标量声明使用：

```text
u16 name initializer?
```

局部一维数组使用：

```text
u16 name[length] initializer?
```

例如：

```c
u16 value = 10;
u16 other;
u16 values[4];
u16 seeded[3] = {compute(), 2,};
```

局部标量初始化和局部数组的每个 initializer 都可以是任意 `u16` 表达式，包括函数调用；元素按源顺序初始化。数组 initializer 数量可以少于长度，缺少的末尾元素初始化为 0。

未初始化局部标量或数组读取的是当前栈 word，不保证为 0。

### 7.3 块

```c
{
    u16 value = 1;
    value += 1;
}
```

块建立局部作用域。同一个活动作用域中不能重复声明同名变量。离开作用域后，该名称不可见，但已经分配的帧空间保留到函数结束。

### 7.4 `if` 和 `else`

```c
if (condition) {
    statement
} else {
    statement
}
```

条件可以是任意 `u16` 表达式；0 为假，非 0 为真。

### 7.5 `while`

```c
while (condition) {
    statement
}
```

每次迭代前检查条件。

### 7.6 `for`

```c
for (initializer; condition; step) {
    statement
}
```

三部分都可省略。初始化可以是声明或表达式：

```c
for (u16 index = 0; index < 10; index += 1) {
    body(index);
}
```

`for` 声明变量的作用域仅限该循环。

执行顺序为：

1. initializer；
2. condition；
3. body；
4. step；
5. 回到 condition。

### 7.7 `break` 和 `continue`

`break` 跳到最内层循环的结束位置。`continue` 跳到最内层循环的 step；没有 step 时直接回到 condition。

两者只能出现在循环内。嵌套循环中的跳转只作用于最内层循环。

### 7.8 `return`

`u16` 函数返回表达式：

```c
return expression;
```

`void` 函数使用：

```c
return;
```

`void` 函数不能返回值，`u16` 函数不能返回 `void` 调用。

函数正常执行到末尾时：

- `void` 函数直接返回；
- `u16` 函数返回 0。

## 8. 作用域

- 参数属于函数最外层作用域；
- 局部变量属于所在块；
- `for` 声明属于该 `for`；
- 全局函数和变量属于翻译单元；
- 不支持 `static`、`extern` 或块级函数；
- 当前实现不允许用局部变量遮蔽参数或另一个活动局部变量。

## 9. 求值副作用

可产生副作用的表达式包括：

- 函数调用；
- 赋值和复合赋值；
- 使用 `&&`、`||` 右侧的计算。

Retro C 不提供 volatile。硬件数据指令、ALU 和函数调用均可能改写通用寄存器。

## 10. 内存和栈

- 地址单位是 16-bit word；
- 启动时 `SP = 0xffff`；
- 栈向低地址增长；
- 参数、标量局部变量和局部数组都位于虚拟栈；
- 局部数组在帧中占用连续的 `N` 个 word；
- 全局数组在程序数据区占用连续的 `N` 个 word；
- 数组下标执行边界检查，越界时以 `RS = 0xffff` 停机；
- 函数支持递归；
- 单函数栈帧最多 8192 words；
- 编译器为表达式 `PUSH/POP` 和调用保留 1024 words 临时空间；
- 代码和数据限制在 `0x0000..0x7fff`；
- 函数序言在扣栈前检查活动栈空间；
- 空间不足时程序跳到 `__stack_overflow`，令 `RS = 0x8400` 并执行 `HLT`，不会继续覆盖低地址程序或栈。

完整的 ABI 和代码生成说明见 [`docs/compiler.md`](compiler.md)。

## 11. 明确不支持的功能

当前语言不提供：

- 指针、多维数组、数组参数和数组整体赋值；
- `char`、`int`、有符号或 32/64-bit 整数；
- 浮点；
- 乘法和取模；
- 自增、自减和逗号运算符；
- 三元运算符；
- `switch`、`goto` 和标签；
- `struct`、`union`、位域；
- 字符串和字符 I/O；
- 预处理器、宏和头文件；
- 多翻译单元和链接器；
- 函数指针和可变参数；
- 静态局部变量；
- 宿主系统调用。

## 12. 数组示例

```c
u16 values[4] = {1, 2, 3};

u16 main(void)
{
    u16 index = 0;
    u16 sum = 0;
    for (index = 0; index < 4; index += 1) {
        sum += values[index];
    }
    return sum;
}
```

缺少的 `values[3]` 初始化为 0，因此最终 `RS` 为 `1 + 2 + 3 + 0 = 6`。

## 13. 完整示例

```c
u16 total;

void add(u16 value)
{
    total += value;
}

u16 bounded_sum(u16 count)
{
    u16 sum = 0;
    for (u16 index = 0; index < count; index += 1) {
        if (index == 2) {
            continue;
        }
        sum += index;
    }
    return sum;
}

u16 main(void)
{
    add(3);
    add(4);
    if (total == 7) {
        return bounded_sum(5);
    }
    return 0;
}
```

`bounded_sum(5)` 跳过 2，结果为 `0 + 1 + 3 + 4 = 8`；因此此程序的最终 `RS` 为 8。
